Software

  • Documentation

TraitBlender is a Blender add-on for generating synthetic museum-style image and 3D mesh datasets. From theoretical or empirical morphospaces, it simulates taxa on phylogenies and renders standardized specimens in bulk—useful when benchmarks need ground-truth evolutionary processes.

  • Paper
  • GitHub

PhyloNN uses restructured autoencoders and multi-task learning to incorporate evolutionary information such as phylogeny and ontogeny into deep learning models for phenotypic data. The goal is to ground high-dimensional or raw datasets in biological structure rather than treating morphology as an unstructured prediction problem.

  • Paper
  • GitHub

RPhenoscate incorporates biological knowledge into comparative analyses through ontologies: knowledge graphs that specify hierarchical relationships between traits. This helps ensure that statistical models reflect biologically meaningful assumptions about how characters relate to one another.

  • Paper
  • GitHub

Revticulate is an R package that provides an interface between R and RevBayes, making it easier to set up, run, and analyze Bayesian phylogenetic inference workflows from within R.

  • GitHub

SISRS (Site Identification from Short Read Sequences) is a phylogenomic pipeline for identifying informative sites and inferring orthologous sequences from short-read genomic data.

  • Live demo
  • GitHub

Species Map Explorer is a classroom web app for exploring where species have been observed and how those patterns relate to geography and climate. Students can map GBIF occurrences, overlay climate and biogeographic layers, and browse related open biodiversity context in the browser.

I built it with the Imageomics Institute for the July 2026 HDR workshop on education in the age of AI, to help teachers introduce comparative biology and species distributions.

  • Live app

EcoEvoJobSearcher is a browser tool for searching ecology and evolutionary biology positions across EcoEvoJobs, EvolDir, and Science Careers. It aggregates listings into one dashboard with filters for source, open applications, deadlines, and posting date, plus a map of where jobs are concentrated and CSV export for offline tracking.
